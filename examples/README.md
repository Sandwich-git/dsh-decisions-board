# 示例数据

`decisions.sample.json` 是三条形状样本（一条带选项、一条「要不要」、一条已定），用它可以不碰真实数据就看清渲染：

```powershell
node tools/serve.mjs --file "<repo>\examples\decisions.sample.json"
# 打开它打印的 http://127.0.0.1:<随机端口>/
```

预期：

- 角标 `待拍 2 · 待发 0`（Q-1 与 Q-2；Q-3 是已定，进「已定（最近 1）」区）；
- Q-1 卡片显示 **建议 A 先发布**，两个选项各带代价；
- Q-2 卡片显示「该条没给选项 —— 默认按「是 / 否」拍。」+ 两个按钮；
- 点任意选项 ⇒ 页面底部输入框出现 `Q-1 选 A（先发布）` 这类句子，**不会发送**。

> 真实使用时数据在 `<会话工作目录>/.dsh/decisions/<sessionId>.json`，由 agent 或人手写，
> 文件不存在时看板就是空的（不报错、不猜）。
