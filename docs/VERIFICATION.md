## 7. 手动关闭（0.5.0）

**要解决的问题**：自动收口只认 `Q-2 选 B` 这一种形态。人用自己的话答、或在会话外答，插件认不出来，
条目就永远挂在「待拍」里 —— 而人除了手改 JSON 没有出口。成本最低的出口是：**让人自己关**。

### 7.1 真机（真 Chromium + 真 HTTP）观测

在预览页（`node tools/serve.mjs --file <示例文件的临时副本>`）用真浏览器点，逐步记录：

| 步骤 | 观测 |
| --- | --- |
| 抽屉打开 | 两条未定卡片各有一个「手动关闭」，与「展开原委」同一行 |
| **第一次**点击 | 按钮文案变成「确认关闭？（它不会发消息）」；`/api/decide` **一次请求都没有** |
| **第二次**点击 | 一个 `POST /api/decide` → **200**；角标 `待拍 2 → 待拍 1`；页面出现复述「已定：Q-2（手动关闭）」 |
| 关闭后刷新页面 | Q-2 落在「已定」：「✓ 已定 手动关闭」+「人工关闭：只表示这条不用再等，没记选项。」+「由 user 于 …」 |
| 输入框 | 全程**没有任何文字被写进去** —— 只填不发的红线在关闭路径上同样成立 |

### 7.2 三个变异各自红在预期断言上

| 变异 | 改的是什么语义 | 红在哪 |
| --- | --- | --- |
| M-1 | 宿主不再把 `dismiss` 当真（开关钉成 `false`） | 恰好 4 条 dismiss 用例红（落库、别名、未知 id、带 value），其余不动 |
| M-2 | `normalizeDoc` 的 decided 投影漏掉 `manual` | 往返断言红：`decided.manual` 读一次盘就变成 `undefined` |
| M-3 | 去掉面板的两步确认（第一次点击就写） | 「第一次点击不能写任何东西（防误触）」断言红 |

> M-2 是这轮唯一「只能靠变异才抓得住」的一条：`normalizeDoc` 里那串是**手写字段清单**，
> 少写一个字段，代码不报错、大部分测试照样绿，只有「写进去 → 读回来 → 再断言」能抓到它。

### 7.3 这轮没验到的

- 只在 Chromium 的**预览页**点过；真 Harness 里的抽屉没有点过（代码路径相同，但属于未验）；
- `decided.at` 仍写成 UTC 的 `…Z`（与选票路径一致），没做本地时区格式化；
- 手动关闭**不可撤销**（要恢复得手改 JSON），也没有「已关闭」列表的翻页。
